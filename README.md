# 班长管理器

一个无需安装依赖的班级收交登记网页。支持电脑、手机浏览器，适合部署到 GitHub Pages。

在线使用：https://zzy-sudo-acm.github.io/class-monitor/

## 本地使用

双击 `打开班长管理器.cmd`，或使用浏览器打开 `index.html`。

需要 HTTP 预览时，在项目目录运行：

```powershell
node server.cjs
```

访问 http://127.0.0.1:4173 。无需执行 `npm install`。

## 使用步骤

1. 点击「录入我的名单」，粘贴班级名单。初次看到的是标明为演示的示例数据。
2. 名单一行一人，例如 `张三 男`、`李四 女`；也可以从 Excel 复制「学号、姓名、性别」三列或读取 CSV。未填写性别时可统一指定。
3. 点击「新建事项」，填写事项名称，例如「语文练习册」。用「收什么」下拉框切换事项，每个事项的提交独立保存。
4. 点击同学旁的「未交」标记已交，再次点击「已交」可撤销。
5. 使用姓名/学号搜索、男生/女生筛选和全部/未交/已交筛选，可以组合使用。
6. 「导出名单」导出当前筛选结果为 CSV；「复制未交」复制当前事项的全部未交同学。
7. 在「班级名单」中添加、编辑或删除同学；在事项旁点击「删除事项」。删除前会说明影响并确认，删除后 10 秒内可点击「撤销删除」。撤销入口只保留最近一次删除，刷新页面后消失。

同名同学请设置不同学号。添加同学会加入进行中的事项。删除事项会删除该事项及提交记录，班级名单和其他事项保留；删除同学会同时移除该同学在所有事项中的记录。

旧版归档事项和已移出的同学仍然兼容，可以恢复或直接删除。新界面使用删除操作。

## 数据保存与备份

名单和提交记录只保存在当前浏览器，不会上传到 GitHub。右上角「更多」包含「备份数据」「恢复备份」和使用说明。换设备、换浏览器或清理浏览器前，导出完整 JSON，在另一设备恢复。CSV 只保存名单，完整 JSON 才包含收交记录。

请固定使用同一个浏览器和打开方式。直接打开文件、本地 HTTP 预览和 GitHub Pages 的浏览器存储相互独立；要迁移数据请导出、恢复完整备份。无痕窗口关闭后可能清除数据。

恢复备份前会提示替换，并先自动导出当前数据备份。保存失败时会提示错误，不会显示为保存成功。多个窗口同时编辑时会检查冲突，并提醒重试。

## GitHub Pages

本项目可直接发布到 GitHub Pages，不需要安装依赖或构建。

发布时，把 `index.html`、`styles.css`、`core.js`、`app.js`、`favicon.svg`、`.nojekyll` 放到仓库。GitHub 仓库 Settings → Pages，选择从 `main` 分支的根目录发布即可。全部资源使用相对路径，支持 `https://用户名.github.io/class-monitor/` 这样的子目录。

仓库只放程序文件，不要提交真实名单、CSV 或个人备份文件。
